# 盗亦有道

中世纪乡下偷窃 RPG（Phaser 3）· 作品集可玩垂直切片。

## 怎么运行

1. 双击 `server.ps1`
2. 浏览器打开：http://localhost:8000
3. 编辑器：http://localhost:8000/editor.html

不要直接双击 `index.html`（`file://` 会大量报错）。

## 操作

| 按键 | 作用 |
|------|------|
| WASD | 移动 |
| Shift | 跑步 |
| E | 互动 / 对话继续 |
| Tab | 背包 |
| H | 打开引导说明 |
| Esc | 关闭对话 / 战斗中逃跑 |

首次进游戏会弹出引导；之后按 **H** 可再看。

## 建议体验（5～10 分钟）

1. 跟村民说话
2. 拾取背包，按 Tab 整理
3. 试开锁搜箱（小心被看见）
4. 被盘问时可辩解、逃跑或伏法
5. 接几个挂在 NPC 上的任务

- **伏法**：罚款 + 限时减益，清除通缉  
- **逃跑**：通缉等级上升  

## 当前版本

`v0.3` 垂直切片 · 进行中原型，非成品。

主要系统：潜行开锁、通缉与伏法、背包战场、节点对话与任务、自研地图/NPC 编辑器。
